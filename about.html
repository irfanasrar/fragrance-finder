About & accessibility

Fragrance Finder is a student web app for Sheffield Hallam University's Web Technologies module. It suggests perfumes from your taste, the occasion and the weather.

Data sources

  • Open Beauty Facts (ODbL) for perfume search and product details
  • Wikidata (CC0) for the brand list on the Finder page
  • Open-Meteo (CC BY 4.0) for city weather used in scent suggestions
  • A local scent-families.json file for family names and descriptions

Accessibility

The site aims to follow W3C accessibility guidance. In particular:

  • Skip link to main content on every page
  • Semantic landmarks, headings and labelled form controls
  • Error messages linked to fields, with an error summary on the Finder
  • Focus styles that stay visible, and Escape closes the mobile menu
  • Respect for prefers-reduced-motion

Built by Irfan Asrar for Web Technologies Assignment 2.
